Step 10의 음소거 해제 버튼을 최초 마이크 획득 버튼으로 자동 전환하지 마세요.

## 7. 로컬 트랙 소유권과 replaceTrack

현재 Step 06~10의 로컬 미디어 구조를 확인해주세요.

특히 다음 관계를 명확하게 유지해야 합니다.

- `useLocalMedia`: 로컬 MediaStream과 획득 트랙 소유
- `useSfuSender`: 해당 트랙을 사용한 SFU Producer 관리
- 로컬 미리보기: 현재 소유 스트림 참조
- 원격 Consumer: 로컬 트랙과 별도 소유권

`Producer.replaceTrack()`에 전달한 새 트랙이 자동으로 로컬 MediaStream의 소유 트랙을 변경하는 것은 아니므로, 실제 Track 및 Stream 참조를 명시적으로 동기화해주세요.

다음 문제가 발생하지 않도록 합니다.

- 이전 트랙 stop 누락
- 새 트랙의 중복 stop
- 이전 트랙이 Stream에 남아 있음
- 새 트랙이 Stream에 등록되지 않음
- 로컬 미리보기가 이전 카메라를 표시
- 컴포넌트 재렌더링 시 옛 트랙으로 Producer 복귀
- SFU 종료 시 로컬 트랙이 의도치 않게 종료
- 장치 교체 중 다른 종류의 트랙 종료

트랙 소유권 이전과 실패 시 복구 순서를 실제 코드 구조에 맞춰 설계해주세요.

기존 `stopTracks:false` 정책을 유지하고, 새로운 트랙의 정리 책임이 명확하도록 해주세요.

## 8. 장치 연결·해제 감지

`navigator.mediaDevices`의 `devicechange` 이벤트를 활용해주세요.

이벤트 발생 시 장치 목록을 갱신하고 현재 선택 장치 및 실제 트랙 상태를 확인해주세요.

다음 상황을 구분합니다.

- 사용하지 않는 장치가 추가됨
- 사용하지 않는 장치가 제거됨
- 현재 선택한 장치가 제거됨
- 현재 사용 중인 장치가 제거됨
- 장치가 다시 연결됨
- 브라우저가 장치 ID 또는 label을 변경함

### 8.1. 현재 사용 중인 장치 제거

현재 사용 중인 장치가 제거되면 다음을 확인해주세요.

- MediaStreamTrack의 ended 상태
- 기존 Producer 및 SFU 송신 상태
- 로컬 미리보기 상태
- UI의 선택 장치 표시
- 사용자에게 제공할 오류 안내

기존 Step 10의 외부 트랙 종료 정책과 충돌하지 않도록 해주세요.

새 장치로 자동 전환할지 사용자 선택을 요구할지는 실제 보안·프라이버시와 기존 명시적 획득 정책을 고려해주세요.

명시적으로 선택한 장치가 사라졌는데 다른 장치를 선택한 것처럼 표시해서는 안 됩니다.

### 8.2. 이벤트 중복 및 정리

`devicechange`가 여러 번 발생할 수 있으므로 중복 조회와 오래된 비동기 응답을 제어해주세요.

컴포넌트 해제 후 이벤트 리스너가 남지 않도록 합니다.

## 11. 다중 회의방 정책 유지

A가 1111과 2222에 모두 소속되어 있고 활성 미디어 회의방이 1111인 상황을 검증해주세요.

- 1111에서 마이크 전환
- 2222 채팅 화면으로 이동
- 1111의 기존 SFU 송수신 유지
- 2222의 별도 미디어 연결 생성 없음
- 2222 채팅 정상 송수신
- 1111 원격 참가자에게 전환 결과 반영

이후 A가 1111에서 2222로 명시적으로 미디어 연결을 전환하면:

- 1111의 송수신 자원 정리
- 로컬 장치 트랙 재사용 여부 확인
- 2222로 새로운 활성 미디어 연결
- 선택된 카메라·마이크 정책 유지
- 카메라 OFF 상태 유지
- 마이크 음소거 상태 유지
- 이전 mediaId의 늦은 장치 전환 응답 무효화

장치 선택을 변경했다는 이유만으로 미디어 회의방이 전환되면 안 됩니다.

## 12. 자동화 테스트

Chromium 가상 장치가 실제로 하나만 제공된다면 단일 가상 장치 전환으로 서로 다른 장치 사이의 전환 성공을 주장하지 마세요.

- 실제 적용 트랙 변경
- 기존 트랙 종료
- Video Producer ID 유지 여부
- Audio Producer ID 유지 여부

- 원격 Consumer 유지

- 영상 프레임 디코딩
- 실패 시 기존 트랙 유지

- 불필요한 Consumer 재생성 없음
- 음소거 해제 전 실제 오디오 송신 없음
- 명시적 음소거 해제 이후 RTP 재개

전환 과정에서 순간적으로 음성이 송신되는 경합을 중점적으로 점검해주세요.

- 자동 카메라 획득 없음
- Video Producer 자동 생성 없음
