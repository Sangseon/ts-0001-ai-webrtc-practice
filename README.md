# ts-0001-ai-webrtc-practice

Codex AI를 활용한 TypeScript 기반 WebRTC 바이브 코딩 실습 프로젝트.

## Documents

- [Concept](./docs/Concept.md) — 프로젝트 개요 및 구현 방향

아래 기능을 구현할 거고 프롬프트로 작업순서 정의 밑 기능구현을 step별로 작성하여 구현하도록 할 계획이다.

```
1. 다자간 화상회의
2. 채팅
	- 전체 채팅
	- 회의방 채팅
3. 캐릭터, 닉네임 변경
4. 장치설정
	- 카메라, 마이크 제어
	- 장치 선택
	- 마이크 테스트
```
